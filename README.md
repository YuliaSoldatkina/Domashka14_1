# Домашняя работа 14.1–14.2

## Описание проекта

Проект представляет собой базовое ядро интернет-магазина, реализованное с
использованием объектно-ориентированного программирования.

## Реализованный функционал

### Домашняя работа 14.1

- Создан класс `Product` для представления товара.
- У товара определены название, описание, цена и количество в наличии.
- Создан класс `Category` для представления категории товаров.
- У категории определены название, описание и список товаров.
- Добавлены атрибуты класса `category_count` и `product_count`.
- Счётчики автоматически обновляются при создании новой категории.

### Домашняя работа 14.2

- Список товаров в классе `Category` сделан приватным атрибутом `__products`.
- Реализован метод `add_product()` для добавления товара в категорию.
- Метод `add_product()` увеличивает общий счётчик товаров.
- Реализован геттер `products`, возвращающий товары строкой в заданном формате.
- Атрибут цены в классе `Product` сделан приватным `__price`.
- Для цены реализованы геттер и сеттер.
- Сеттер не позволяет установить нулевую или отрицательную цену.
- Реализован класс-метод `Product.new_product()` для создания товара из словаря.
- Написаны тесты для исходной и новой функциональности.
- Создан XML-отчёт о покрытии тестами `coverage.xml`.
- Код проверяется с помощью `flake8`.

## Установка и запуск

Для установки зависимостей выполните:

```bash
poetry install
```

Для запуска тестов:

```bash
poetry run pytest -v
```

Для формирования отчёта покрытия:

```bash
poetry run pytest --cov=src --cov-report=term-missing --cov-report=xml
```

Для проверки стиля кода:

```bash
poetry run flake8 src tests main.py
```

Для запуска демонстрационного файла:

```bash
poetry run python main.py
```


## Домашняя работа 16.1

В проект добавлена поддержка различных типов товаров с использованием
наследования.

- Создан класс `Smartphone`, наследующийся от `Product`.
- Для смартфона добавлены атрибуты `efficiency`, `model`, `memory` и `color`.
- Создан класс `LawnGrass`, наследующийся от `Product`.
- Для газонной травы добавлены атрибуты `country`, `germination_period` и
  `color`.
- Метод `Product.__add__()` позволяет складывать стоимость запасов только
  товаров одного класса.
- При попытке сложить объекты разных классов вызывается `TypeError`.
- Метод `Category.add_product()` принимает только объекты `Product` и его
  классов-наследников.
- При попытке добавить объект другого типа вызывается `TypeError`.
- Для новой функциональности написаны тесты.
- Покрытие кода тестами составляет 100%.
