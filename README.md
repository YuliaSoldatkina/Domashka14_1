# Домашняя работа 14.1

## Описание проекта

Проект представляет собой базовое ядро интернет-магазина, реализованное с
использованием объектно-ориентированного программирования.

## Реализованный функционал

- Создан класс `Product` для представления товара.
- У товара определены название, описание, цена и количество в наличии.
- Создан класс `Category` для представления категории товаров.
- У категории определены название, описание и список товаров.
- Добавлены атрибуты класса `category_count` и `product_count`.
- Счётчики автоматически обновляются при создании новой категории.
- Написаны тесты для проверки классов и подсчёта категорий и товаров.
- Настроена проверка качества кода с помощью `flake8`.
- Создан XML-отчёт о покрытии тестами `coverage.xml`.

## Установка и запуск

Для установки зависимостей выполните:

```bash
poetry install
```

Для запуска тестов выполните:

```bash
poetry run pytest -v
```

Для формирования отчёта о покрытии выполните:

```bash
poetry run pytest --cov=src --cov-report=term-missing --cov-report=xml
```

Для проверки стиля кода выполните:

```bash
poetry run flake8 src tests
```
